# C++ HackerRank Practice

Standalone C++ practice solutions covering input/output, strings, arrays, pointers, inheritance, and standard-library containers and algorithms.

## Usage

Compile one source file at a time, for example `g++ -std=c++17 helloWorld.cpp -o /tmp/hackerrank-hello`, and provide the input expected by that exercise.
